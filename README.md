# Biohackn

Biohackn is a premium wellness and biohacking website designed to showcase high-performance recovery and longevity solutions, including infrared saunas, cold plunge therapy, red light therapy, and hyperbaric wellness systems.

## Overview

This project is a static marketing website built with HTML, CSS, and JavaScript. It presents Biohackn as a modern wellness brand focused on performance, recovery, and everyday vitality.

## Features

- Clean, conversion-focused landing page
- Product showcase sections
- Customer testimonials and trust-building content
- FAQ accordion for user education
- Contact form and WhatsApp CTA
- Responsive layout for mobile and desktop screens
- Multi-page structure for product, blog, and policy content

## Project Structure

- `index.html` – homepage
- `style.css` – styling and layout
- `script.js` – interactivity, FAQ toggle, nav behavior, smooth scrolling
- `infraredSaunas.html` – infrared sauna product page
- `coldPlunges.html` – cold plunge product page
- `redlight.html` – red light therapy page
- `hyperbaric.html` – hyperbaric systems page
- `blog1.html`, `blog2.html`, `blog3.html` – blog articles
- `faq.html` – FAQ page
- `privacypolicy.html` – privacy policy
- `terms.html` – terms and conditions
- `Gideon.jpg` – brand image asset

## Technologies Used

- HTML5
- CSS3
- JavaScript
